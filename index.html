Politique de confidentialité — Carte Go

Dernière mise à jour : 7 octobre 2026

Bienvenue sur Carte Go, une application Android développée par Séverin.

Cette Politique de confidentialité explique comment Carte Go traite les informations lorsque vous utilisez l'application.

1. Informations générales

Carte Go est une application destinée à faciliter la lecture des codes de recharge figurant sur les cartes de recharge téléphonique.

L'application peut prendre en charge les opérateurs Orange, YAS et Airtel, selon les fonctionnalités disponibles dans l'application.

Carte Go est conçue pour limiter la collecte d'informations personnelles au strict nécessaire au fonctionnement de l'application.

2. Utilisation de la caméra

Carte Go utilise la caméra du téléphone afin de permettre la lecture du code de recharge présent sur une carte.

L'autorisation d'accès à la caméra est demandée uniquement lorsque cette fonctionnalité est nécessaire.

Les images provenant de la caméra sont utilisées pour permettre la détection et la lecture du code de recharge.

Les images capturées par la caméra ne sont pas envoyées à nos serveurs, vendues ou partagées avec des tiers à des fins publicitaires.

3. Reconnaissance du code

Carte Go peut utiliser une technologie de reconnaissance optique de caractères (OCR) afin d'identifier les chiffres du code de recharge.

L'application cherche notamment à reconnaître un code composé de 14 chiffres.

4. Données personnelles

Carte Go ne nécessite pas obligatoirement la création d'un compte utilisateur.

L'application ne demande pas, pour son fonctionnement normal :

  • votre nom complet ;
  • votre adresse personnelle ;
  • votre numéro de téléphone personnel ;
  • votre adresse e-mail ;
  • votre mot de passe ;
  • vos contacts ;
  • vos messages ;
  • vos photos personnelles.

Nous ne vendons pas de données personnelles à des tiers.

5. Données stockées sur l'appareil

Certaines préférences peuvent être enregistrées localement sur votre appareil afin d'améliorer votre expérience.

Par exemple, si vous choisissez de mémoriser l'opérateur sélectionné, cette préférence peut être conservée localement sur votre téléphone.

6. Utilisation du code de recharge

Lorsque l'utilisateur valide un code de recharge, Carte Go peut utiliser le format correspondant à l'opérateur sélectionné afin de faciliter l'utilisation du service de recharge.

Carte Go n'est pas un opérateur téléphonique et ne remplace pas les services officiels d'Orange, YAS ou Airtel.

7. Services tiers

Carte Go peut fonctionner avec certains services ou fonctionnalités du système Android nécessaires à son fonctionnement.

Lorsque des services tiers sont utilisés, leurs propres politiques de confidentialité peuvent également s'appliquer.

8. Publicité

Carte Go ne collecte pas de données personnelles à des fins de vente ou de publicité ciblée.

9. Sécurité

Nous prenons des mesures raisonnables pour limiter les risques liés au traitement des informations utilisées par l'application.

Cependant, aucune méthode de stockage ou de transmission électronique ne peut être garantie comme étant totalement sécurisée.

10. Enfants

Carte Go n'est pas spécifiquement destinée aux enfants et nous ne cherchons pas à collecter volontairement des informations personnelles auprès des enfants.

11. Modifications de cette politique

Cette Politique de confidentialité peut être modifiée lorsque l'application évolue ou lorsque de nouvelles fonctionnalités sont ajoutées.

La date de dernière mise à jour sera modifiée lorsque des changements importants seront apportés.

12. Suppression des données

Carte Go ne nécessite pas obligatoirement la création d'un compte personnel.

Les préférences enregistrées localement peuvent être supprimées en effaçant les données de l'application ou en désinstallant l'application depuis les paramètres Android.
